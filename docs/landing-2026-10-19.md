# Language landing page: 19 October 2026

[All guides](README.md)

The root address now serves a language chooser instead of the English framework.
The English framework remains at `/en`. The hidden home page uses `landing.md`;
the shared language list continues to include only the 13 visible language editions.
Startup migrates an existing `/en` home alias to `/home`, preserving other runtime
configuration values. Fresh installations use the new alias directly.

The native dialog has a centred logo and project name, descriptive language links,
an accessible name, initial heading focus, and keyboard focus wrapping. The picker
stays open until a language is chosen: there is no close button or background copy,
and Escape and backdrop clicks do not dismiss it. Without JavaScript, the open dialog
still presents ordinary language links. Existing light/dark and text-size
preferences apply. Language links have no underlines and reuse the existing
`va_language_menu` cookie and shared script for relative click-history shading.

Language pages marked `translation_review: machine-draft` display a small warning
triangle, an accessible draft-status label, and a reference to the explanation
below the buttons. The explanation invites people and groups to adopt a language
and links to Contact. Kaaps also carries an amber community-review warning, while
SASL has a green pending-edition icon and its own explanatory note. English remains
unflagged. Icons use amber or pale green fills, with dark
outlines and marks, and are supplemented by text;
the status does not depend on colour alone.

Checks passed: root routing, all 13 destinations, English at `/en`, existing language
navigation, modal focus and names, keyboard operation, blocked dismissal,
cookie-based shading, no-JavaScript navigation,
320-pixel layouts at 400% text size in both themes, PHP/JavaScript/shell syntax,
and automated WCAG-tagged axe checks. Visual review confirmed the centred logo
and name are visible when the modal opens. Screen-reader review remains outstanding;
these checks do not establish WCAG conformance.

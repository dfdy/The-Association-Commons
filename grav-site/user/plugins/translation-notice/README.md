# DDC: Translation Notice

Place `[translation-notice /]` on its own line to show the machine-translation warning, canonical English counterpart and translation volunteer invitation. Links follow the current page route: `/zu/stadgar` links to `/en/stadgar` and the `/zu` proposal. Keep corresponding English routes available when adding translated pages.

The notice is English text marked `lang="en"`. It uses a semantic aside, visible text and border as well as amber colour, underlined links, keyboard focus outlines and forced-colour support. Markdown downloads retain the notice as prose and links.

Validation: PHP syntax checked in the local Grav container. HTTP checks covered all 45 pages (36 notices on non-English pages; none on English pages), expected canonical/proposal links, CSS inclusion, shortcode expansion and a Markdown download. Browser keyboard, zoom, forced-colour and screen-reader testing remain unperformed. The notice uses native links and has no scripted interaction.

Use this feature to explain terms where readers need them. Start with a short,
concrete definition, and ask whether someone new to the discussion can understand it.
The example below goes in the page body; replace its sample term and definition.

## Editor and maintainer reference

Part of The Democratic Development Commons **0.3.2**.

Group explicit Markdown entries in a glossary. Each entry keeps a real heading and paragraph for screen readers and exports:

```markdown
[glossary]

[glossary-entry]

### Shared purpose

The common aim that brings an association together and guides its work.

[/glossary-entry]

[/glossary]
```

Move or add complete entries in Markdown. Cards use the original site’s sage panels and italic serif terms, with two columns on desktop and one on mobile. Night mode and print are supported. No JavaScript is required. Downloads omit standalone wrapper markers and retain headings and definitions; fenced shortcode examples remain literal. Use heading levels appropriate to the surrounding document.

The plugin is available across language editions. Glossary wording follows each
page's content; translated drafts still need speaker review. Changes to English
definitions are not automatically propagated to existing translations.

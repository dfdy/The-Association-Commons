# DDC: Translation Notice

[Editing guide](../../../docs/operations.md) · [All guides](../../../docs/README.md)

This notice tells readers when an edition is a machine-generated draft and links
them to its English source and participation page. Keep the notice while that
status applies. A translated-looking page does not by itself show speaker review
or community agreement. The shortcode below is for page editors. The shared notice
also remains on the Kaaps edition, whose proposal contains user-supplied reviewed
text but still invites community review, and on SASL's written-English support pages.
Those pages' metadata and landing-page indicators distinguish their status.

## Editor and maintainer reference

Part of The Democratic Development Commons **0.3.2**.

Place `[translation-notice /]` on its own line to show the machine-translation warning, canonical English counterpart and translation volunteer invitation. Links follow the current page route: `/zu/stadgar` links to `/en/stadgar` and the `/zu` proposal. Keep corresponding English routes available when adding translated pages.

The notice is English text marked `lang="en"`. It uses a semantic aside, visible text and border as well as amber colour, underlined links, keyboard focus outlines and forced-colour support. Markdown downloads retain the notice as prose and links.

The brown warning triangle sits above the heading, with a subtly shaded interior.
The text also identifies the warning, so its meaning does not depend on the icon or
colour. A stylesheet content hash prevents browsers retaining obsolete icon styles.

Checks cover translated proposal and supporting-page notices, canonical links,
shortcode expansion, exports, icon placement and colours in both themes, and the
forced-colour fallback. Screen-reader review remains outstanding. Historical
checks describe earlier page trees; see the release notes for current verification.

# Nikela kule projekthi.

Iindlela zokunikela ziya kudweliswa apha.

## Iindlela zokunikela ziyeza kamva

Eli phepha lilungiselelwa ukhetho lwexesha elizayo lweprojekthi. Akukho ndlela zokuhlawula okanye iinkcukacha zebhanki ezipapashiweyo okwangoku.

Iprojekthi iceba ukuseka umbutho ongenzi nzuzo. Iinkcukacha zombutho ziya kongezwa xa zikhona; Eli phepha alibangi ubume beNPO, PBO okanye icandelo 18A.
